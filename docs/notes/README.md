# Engineering notes

These retain research and experiment details without defining current product
status. Start with the [project README](../../README.md).

- [Save-system investigation](save-system-research.md): historical GBVM snapshot
  analysis. Its mid-run resume proposal was superseded by hideout-only semantic
  records; it is not the implemented save specification.
- [Scene pipeline experiments](scene-pipeline-experiments.md): staged API probes,
  schemas, dashboards, evidence and limits. For current entry points see the
  [pipeline guide](../../the-pale-cap/art-tests/jev-scene-probe/README.md).
- [Design history](design-history.md): earlier proposals and implementation
  checkpoints, superseded where necessary by the [current design](../../the-pale-cap/DESIGN.md).

Generated binary measurements retain their original hashes. Machine paths have
been made repository-relative or expressed against `GB_STUDIO_ROOT`; that is
path normalization, not a claim that old artifacts were rebuilt.
