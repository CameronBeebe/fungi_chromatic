# README captures

These are unretouched 160×144 **PyBoy emulator screenshots**, not photographs
of a physical Chromatic. The README enlarges them with HTML dimensions.

Captured October 21, 2026:

- `hearth-emulator.png`: integrated game, New Game → Root Hearth.
- `overworld-emulator.png`: same ROM, Hearth → Exit → overworld.
- `heartwood-emulator.png`: standalone offline example, initial playable room
  from its automated native-ROM verification (`before.png`).

Integrated ROM: 262,144 bytes, built with the official GB Studio 4.3.2 CLI from
tracked files at `b1d29de` (no local concept art or prior generated build).
SHA-256: `d8fac4895098f2c33845356c96d909765cc5b009167e4c57bb16e888fab5265b`.
The home/extraction/save/cold-boot emulator suite passed on this binary.

Heartwood ROM: 65,536 bytes; seed candidate `4bf3215496093388`, GBDK 4.5.0.
SHA-256: `e30b2961ada603e569df5bd920c04c4ffd0b0f15cab42ec855ee6e591e2d8fc0`.
It is a separate experimental room, not a level in the integrated game.

Original hardware photos/GIFs may be added later with separate provenance.
These captures do not establish physical display, audio or cartridge behavior.
