What this study does

A separate vision model proposed names, descriptions and labels. Jev saw the same decoded artwork, local crops and those proposals. The Inspect selection uses explicit provisional review cutoffs; all original judgments remain available.

This browser study enables Inspect only. It does not move Bram, award resources or replace the ROM. Harvest art states, actual navigation and native text layout are still to be implemented.
